---
name: drup-new
description: Create git worktrees for a task across one or more repos in the current workspace directory. Use when the user runs /drup-new with a comma-separated repo list and a branch name (e.g. `/drup-new <repo1>,<repo2> bug/auth-bug`).
---

Invoke via bash:
`drup new $ARGS`

Print `drup`'s stdout/stderr verbatim. Do not summarize.
