---
name: ws-use
description: Switch the dev containers to serve a different branch by checking out that branch in each main repo (detaching the worktree first if it owns the branch). Reads per-repo config from the workspace's `.ws.json`. Use when the user runs /ws-use <branch> (or /ws-use with no arg to print current branches).
---

Invoke via bash:
`ws use $ARGS`

Print `ws`'s stdout/stderr verbatim. Do not summarize.
