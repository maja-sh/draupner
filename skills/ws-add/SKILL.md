---
name: ws-add
description: Add repo(s) to an existing task worktree in the current workspace directory. The task's stack must be down first (`ws down <branch>`). Use when the user runs /ws-add with a comma-separated repo list and an existing branch name (e.g. `/ws-add <repo3> feat/existing-branch`).
---

Invoke via bash:
`ws add $ARGS`

Print `ws`'s stdout/stderr verbatim. Do not summarize.
