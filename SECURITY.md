# Security Policy

Please report vulnerabilities privately via GitHub's [private vulnerability
reporting](https://github.com/maja-sh/wsx/security/advisories/new) rather than
opening a public issue or pull request.

Expect an acknowledgement within a few days. If a fix is warranted, we'll
coordinate a release and a disclosure window with you before publishing details.

## Supported versions

Only the latest minor version receives security fixes. `wsx` is pre-1.0, so
upgrades should be straightforward.
